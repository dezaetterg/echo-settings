## О проекте

**Echo Settings** — это современная, быстрая и модульная панель управления операционной системы Linux, разработанная на **Qt 6 (PySide6)** в эстетике **Liquid Glass / Tahoe**. Приложение предоставляет интуитивный интерфейс для управления всеми системными параметрами рабочего стола, оборудованием и сопутствующими утилитами экосистемы Echo.

---

## Основные возможности

### 🎨 Оформление и персонализация (Appearance)
* **Темы оформления**: Светлая, Тёмная и адаптивная системная тема.
* **Акцентные цвета**: Выбор акцентного цвета интерфейса с динамическим предпросмотром компонентов.
* **Менеджер обоев**: Встроенная галерея системных обоев высокого разрешения и выбор пользовательских изображений в реальном времени.

### 🖥 Мониторы и дисплеи (Display & HDR)
* **Многомониторные конфигурации**: Визуальное интерактивное перетаскивание и расстановка мониторов.
* **Параметры экранов**: Разрешение, масштабирование (HiDPI / Fractional Scaling), частота обновления (Hz), ориентация.
* **Комфорт для глаз**: Ночной режим (Night Light) с регулировкой цветовой температуры и поддержка HDR.

### 📶 Сети и Wi-Fi (Network & Connectivity)
* **Wi-Fi менеджер**: Сканирование доступных беспроводных сетей, отображение уровня сигнала и защищенное подключение.
* **Проводная сеть (Ethernet)**, VPN соединения и настройка сетевых прокси.
* **Bluetooth**: Поиск, сопряжение и управление беспроводными устройствами (мыши, наушники, геймпады).

### 🔊 Звук и мультимедиа (Sound & Audio)
* **Интеграция с PipeWire / PulseAudio**: Раздельное управление громкостью динамиков и микрофонов.
* **Селектор устройств**: Быстрое переключение источников вывода и ввода звука.
* **Баланс и системные сигналы**: Тестирование каналов и выбор звуков уведомлений.

### 🔋 Питание и производительность (Power)
* **Профили энергопотребления**: «Производительный», «Сбалансированный» и «Энергосберегающий».
* **Индикатор аккумулятора**: Уровень заряда батареи, время работы и статус питания.
* **Таймауты**: Настройка выключения экрана и перехода в спящий режим при бездействии.

### 🖱 Мышь и тачпад (Mouse & Touchpad)
* **Управление курсором**: Скорость указателя, ускорение и профили отклика.
* **Тачпад**: Естественная прокрутка (Natural Scrolling), касание для клика (Tap to Click) и системные жесты.

### ⌨️ Клавиатура и хоткеи (Keyboard)
* Управление раскладками клавиатуры и горячими клавишами переключения.
* Задержка и скорость автоповтора ввода.
* Настройка глобальных сочетаний клавиш.

### 🔒 Конфиденциальность и безопасность (Privacy)
* **Службы геолокации**: Управление доступом приложений к определению местоположения.
* **Камера и микрофон**: Мониторинг и контроль аппаратных разрешений.
* **Диагностика**: Управление отправкой отчетов об ошибках и журналов.

### 💾 Дисковое пространство (Storage)
* **Интерактивный анализатор**: Наглядная диаграмма занятого места по типам (Система, Приложения, Документы, Мультимедиа).
* **Очистка**: Удаление временных файлов, кэша пакетов и очистка корзины в один клик.

### 🔔 Уведомления (Notifications)
* Глобальное управление всплывающими баннерами и звуками уведомлений.
* Индивидуальные параметры для каждого установленного приложения.
* Режим «Не беспокоить» (Do Not Disturb).

### 🔍 Интеграция с Echo Search
* Прямое управление параметрами встроенного лаунчера **Echo Search** (прозрачность, анимации, модули поиска, фильтры выдачи).

## Архитектура и технологии

* **Интерфейс**: PySide6 (Qt 6.5+) с кастомными виджетами и плавными переходами.
* **Системные шины (IPC)**: D-Bus (GSettings, NetworkManager, UPower, PipeWire, BlueZ).
* **Локализация**: Встроенный мультиязычный модуль (Русский / Английский).

## Установка

### 1. Универсальный скрипт установки (Рекомендуется)
```bash
git clone https://github.com/dezaetterg/echo-settings.git
cd echo-settings
chmod +x install.sh
./install.sh
```

### 2. Установка через deb-пакет (Debian / Ubuntu / Linux Mint / PikaOS)
Скачайте готовый `.deb` пакет со страницы [Releases](https://github.com/dezaetterg/echo-settings/releases) и выполните:

```bash
sudo apt install ./echo-settings_1.0.1_amd64.deb
```

### 3. Запуск из исходного кода
```bash
# Клонирование репозитория
git clone https://github.com/dezaetterg/echo-settings.git
cd echo-settings

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python3 main.py
```

## Системные требования

* **ОС**: Linux (Ubuntu 22.04+, Debian 12+, Linux Mint 21+, PikaOS, Fedora 39+, Arch Linux)
* **Python**: 3.10 или новее
* **Библиотеки**: `PySide6`, `psutil`, `dbus-next`, `jeepney`
* **Окружение рабочего стола**: GNOME, Cinnamon, KDE Plasma, XFCE (Wayland или X11)
